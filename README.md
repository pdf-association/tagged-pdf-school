# Tagged PDF School — community feedback

Welcome. This repository is the **public place to report issues, share feedback, and discuss improvements** for **[Tagged PDF School](https://taggedpdfschool.pdfa.org)**—an educational platform for **tagged (logically structured) PDF**: structure tags, attributes, PDF/UA-oriented concepts, and hands-on experimentation.

Tagged PDF School is an initiative associated with the **[PDF Association](https://pdfa.org)**.

## What this repository is

| Purpose | Yes |
| -------- | --- |
| Bug reports and unexpected behavior on the website | Yes |
| Feature requests and ideas for the product | Yes |
| Corrections or suggestions for educational content (tags, attributes, Matterhorn-related material, etc.) | Yes |
| Questions that should become actionable work (clarify what you need) | Yes (or use **Discussions** if enabled) |

## What this repository is not

- **This repository does not contain the Tagged PDF School application source code.** It exists so everyone can participate via GitHub **Issues** (and **Discussions**, if enabled) without needing access to private development repositories.
- It is not a substitute for **formal standards interpretation** or **vendor support** for third-party PDF tools. For industry context and resources, see the [PDF Association](https://pdfa.org).

<h2 id="source-code-access-reuse-twg">Source code access (Reuse TWG)</h2>

The Tagged PDF School **application** is developed in a **private** repository; this public repository is only for community feedback. **PDF Association members** who take part in the **Reuse TWG** (Technical Working Group) are eligible for access to that private repository. If you are a member in the Reuse TWG and need access, use the usual PDF Association or TWG contact channels.

## Use the product

- **Production:** [https://taggedpdfschool.pdfa.org](https://taggedpdfschool.pdfa.org)
- **Default English entry:** [https://taggedpdfschool.pdfa.org/en](https://taggedpdfschool.pdfa.org/en)
- The site is available in multiple languages via the `en`, `sk`, `de`, `fr`, `es`, and `cn` path prefixes.

Main areas of the site include the **Playground**, **Tags** / **Attributes** / **Properties** reference, **Matterhorn**-oriented views, **Content**, and **Knowledge base** (including machine-readable exports). Explore the navigation from the home page.

## How to report an issue or request a feature

**Fast path (from the website):** use the **Report issue** control on the site when available—it opens GitHub with helpful context already filled in.

**Direct link:** [Open a new issue](https://github.com/pdf-association/tagged-pdf-school/issues/new)

If this repository has the **Discussions** tab enabled on GitHub, use it for open-ended questions; use **Issues** for bugs and concrete, trackable requests.

### Please include

- **Page URL** (copy from the address bar), or the exact screen/feature.
- **What you expected** vs **what happened**.
- **Steps to reproduce** (for bugs), or a clear **use case** (for features).
- **Browser and OS** (and any assistive technology if relevant to accessibility).
- **Screenshots or short screen recording** if they make the problem obvious.

### Labels and scope

Maintainers may use labels to triage (for example: bug, enhancement, content, accessibility). You do not need to pick labels yourself.

## Security

If you believe you have found a **security vulnerability**, do **not** file a public issue with exploit details. Use the **Security** policy for this repository (see the **Security** tab on GitHub) or contact the maintainers as described there. If no policy is published yet, open a minimal issue asking for a **private** contact channel instead of posting sensitive details in public.

## Code of conduct

This project follows the repository’s **Code of conduct** (see the `CODE_OF_CONDUCT` file or the **Community** section on GitHub). Be respectful, assume good intent, and keep feedback constructive.
